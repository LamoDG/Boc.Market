# App nativa con Expo + React Native + TypeScript

Necesitamos Android e iOS con cámara, lector de QR y almacenamiento local, mantenidos por un equipo pequeño que trabaja con agentes. Expo da un solo código, módulos oficiales para cámara, QR y SQLite, y builds sin tocar código nativo. Descartados: PWA (el usuario quiere app de tiendas y propinas con compra integrada) y Flutter (menor encaje con el ecosistema TypeScript).
